# 2-minute demo recording plan

No narration needed. Just show it working. Use OBS / Windows Game Bar (Win+G) / Loom, upload to YouTube as **Unlisted**.

1. (0:00-0:15) Open the deployed site. Show the Route 177 header.
2. (0:15-0:45) "To SLIIT", pick a weekday, set 07:40, click **Check this bus**. Shows Packed / Can't board + tip. Click **Check the 07:10 bus** suggestion.
3. (0:45-1:05) Scroll to **The whole day**. Click a midday bar (seats free), then an evening bar.
4. (1:05-1:15) Switch to **From SLIIT**, click a 17:50 bar.
5. (1:15-1:40) In **Just got off a 177?** type a stop and tap **Packed**. Show "Report saved" and the report appearing in **Recent rider reports**.
6. (1:40-2:00) Open the Supabase table editor (crowd_reports) and show the new row. Optional: open `<api-url>/docs` to show the API.

Tip: if you record before 21:00 Sri Lanka time and check a bus close to now after submitting a report, "Live rider reports used" goes up to 1, which proves the blending works.
